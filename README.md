# Library Management System

A Java-based Library Management System developed as a 5-member group project.

## Responsibilities

| Member | Responsibility | Java Files |
|--------|----------------|------------|
| Member 1 | OOP Architecture + Book Management | `LibraryEntity.java`, `Book.java`, `ReferenceBook.java`, `BookManager.java` |
| Member 2 | Member Management + File Persistence | `Member.java`, `MemberManager.java`, `FileManager.java` |
| Member 3 | Issue & Return Management | `IssueRecord.java`, `IssueManager.java` |
| Member 4 | Exceptions + Reports | Exception classes, `ReportManager.java` |
| Member 5 | Swing GUI + Integration | All GUI classes, `Main.java` |
| Everyone | Testing, report, presentation | — |

## Technologies

- Java
- Object-Oriented Programming (OOP)
- Java Swing
- File Handling
- Git & GitHub
